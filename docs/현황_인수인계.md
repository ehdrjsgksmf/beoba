#### ct_court_document — 「기한이 정해져 있어요」를 어떻게 내렸나

**빼지 않고 물음으로 내렸습니다.** 모든 법원 서류에 기한이 있는 것은 아니고
어떤 서류인지도 우리가 모르는데, 급하게 움직이게 만드는 말이었습니다(270 ② + ⑤).

```
후    이건 혼자 판단하기 어려운 서류예요.
      이 서류에 기한이 있는지도 아래 창구에서 함께 물어보세요.
```

★ **`openPart` / `askThis` 로는 못 갔습니다.** 그 칸은 카드당 하나인데 이
카드의 한 칸은 **비용 물음**(「제가 이의신청이나 답변서를 내는 데 돈이 드나요?」)이
이미 쓰고 있고, 갚는 쪽 비용을 담는 항목이 따로 없어 그 물음을 옮길 데도
없었습니다. **비용 물음을 밀어내지 않았습니다.**

그래서 **카드 문장 안에 물음으로 남기고**, 왜 그랬는지를 `noBasis` 에
적었습니다. 대가는 이것입니다 — **이 한 줄은 글의 〔가서 물어보실 것〕에 안
나갑니다.** 그 자리는 `askThis` 만 나릅니다.

★ 그래서 **`openPart`·`askThis` 를 리스트로 여는 것이 다음 선결입니다.**
모델·스키마·검사·글·화면까지 스물다섯 파일쯤 걸립니다(DECISIONS 274).

★ 묶음 이름에는 쉬운 말을 **안 붙였습니다.** 쉬운 말 모드에서 재도 0.928화면으로

### ★ 40자를 놓아 주는 자리 (DECISIONS 265)

**40자는 수단이지 목적이 아닙니다.** 목적은 한국어가 서툰 분이 읽을 수 있게
하는 것이고, 거기서 주범은 **어려운 낱말**입니다. 열거를 담은 문장은 40자
아래로 쪼개려면 서술어를 되풀이해야 해서 **쪼갤수록 길어집니다.**

```json
"plainLongOk": { "cautions.ct_x.consequence": "왜 놓아 주는지 한 줄" }
```

```
놓아 주는 것    tooLong 하나뿐입니다
그대로 막는 것  이어 붙임 · 시키는 말 · 이중피동 · 단정해짐 · 「수 있」 사라짐
이유가 비면     놓아 주지 않고 SchemaValidator 가 실패로 잡습니다
```

★ 이유를 요구하는 까닭은 `expectsEveryDomain` 의 `skipped` 와 같습니다 —
**일부러 놓아 준 것과 그냥 긴 것은 데이터에서 똑같이 생겼습니다.**

★ 한 분야에서 **절반을 넘으면 경고**합니다. 넘으면 그 분야에서 40자는
사실상 없는 것입니다. 그리고 전체가 쉬운 말 자리의 **1할을 넘으면** 숫자
자체를 다시 봅니다(265번의 되돌릴 조건).

**합계는 여기 안 적습니다.** 검사 (x)가 낼 때마다 셉니다 —
`melos run verify` 의 「40자를 놓아 준 자리 N곳 / 쉬운 말 자리 M개」 줄입니다.
분야별 숫자는 위 표에 있고 그 표는 검사가 맞대 봅니다(238번).

★ 놓아 준 이유는 **셋뿐**입니다. 넷째가 생기면 그때는 40자라는 숫자를
의심할 때입니다.

```
① 조문을 그대로 옮긴 인용    자르면 인용이 아니게 됩니다
② 하나로 걸리는 조건        「~거나 ~면 ~한다」를 쪼개면 조건이 따로 섭니다
③ 열거                   쪼개려면 서술어를 되풀이해야 해서 길어집니다
```

★ **제일 위험한 것은 어려운 낱말이 아니라 미끄러진 어미입니다.**

```
~할 수 있어요  →  ~하면 돼요     지시가 됐다
~일 수 있어요  →  ~예요          단정이 됐다
```

검사 (x)가 **원래 문장과 나란히 놓고** 잽니다(`PlainKoreanCheck`). 규칙은
40자 · 서술어 하나 · 이중부정 금지 · 이중피동 금지 · 용어 보존 · 어미 강도
대조입니다. **피동은 막지 않고 셉니다** — 「최소화」는 0으로 만들라는 말이
아니고, 넓게 막으면 오탐이 납니다(39번).

★ **검사가 도구가 아니라 라이브러리에 있습니다.** 도구에 두면 「검사가 있다」
까지만 말할 수 있습니다. 산재 52자리를 **원래 문장 그대로** 넣어 보면
40자 넘음 23건 · 서술어 이어 붙임 3건이 걸립니다.

### ★ 「이 말을 그대로 보여 주세요」

기관 이름과 서식 이름을 한국어 그대로 크게 보여 주고 복사 버튼을 답니다.

★ **이름을 지어 쓸 수 없습니다.** 여기 적는 말은 그 절차가 이미 들고 있는

우리가 그 항을 안 뽑은 것**이었습니다. 법률 원문에서 네 항을 더 뽑아

★ **조문이 「공단」이라고만 쓰면 이름을 정하는 조문(제10조)을 함께 답니다.**
안 그러면 화면의 「근로복지공단」이 근거 없이 떠 있게 됩니다.

★ **서식 이름은 진짜로 없습니다** — 법률에 없고 고용노동부령 별지입니다.
`openPart` 로 적어 두었습니다.

### ★ 체류자격 (DECISIONS 234)

산재보험법 제6조는 「근로자를 사용하는 모든 사업 또는 사업장에 적용한다」
까지만 적고 체류자격에는 아무 말이 없습니다. **그러니 어느 방향으로도

### ★★ 얼마나 걸리나 (DECISIONS 217 · 220 · 221)

느린 4G(400ms · 400kb/s)에서 잰 값입니다. **넷을 나란히 놓아야 뜻이 있습니다.**

```

(가) CDN · 압축 없음     5,047,755      101.2초   ← 아무도 안 겪는 값입니다
(나) CDN · gzip          2,637,136       53.0초
(다) 로컬 · gzip         3,174,240       63.5초   ← 끊었더니 느려졌습니다
(라) 로컬 · brotli       2,402,215       48.5초   ← 지금 이것으로 갑니다
```

★ **`py -m http.server` 는 압축을 안 합니다.** (가)로 재면 결론이 통째로
틀립니다. 재는 도구를 `serve_gz.py` 로 바꿨고 **압축이 기본**입니다
(`--no-gzip` 을 줘야 끕니다. `--brotli` 로 켭니다).

★ **CDN 을 끊는 것과 brotli 를 켜는 것은 한 몸입니다.** gstatic 이 brotli 로
주고 있었습니다 — CanvasKit 이 거기서는 1,556KB 인데 우리 gzip 에서는

### ★★ 무게 줄이기는 여기서 멈췄습니다 (DECISIONS 225)

48초는 **400kb/s 라는 가정**이 만든 값입니다. 지하철 터널 수준이고,
한국 LTE 는 보통 1~10Mbps 입니다. 같은 빌드로 나눠 재 봤습니다.

```
전송 2,402,215 바이트 (로컬 · brotli)

400kb/s   48.4초    지하철 터널
1Mbps     20.3초
3Mbps      7.1초    보통 쓰는 속도
```

★ **남은 무게의 64%가 CanvasKit(1,541KB)** 이고 Flutter Web 을 쓰는 한 못
줄입니다. `2,402,215 ÷ 51,200 = 47초` — **48초는 그 크기가 정한 바닥**입니다.

앞서 다음 자리로 적어 뒀던 둘 중 하나는 **값이 안 나오고**, 하나는
**값은 나오는데 안 쓰기로 했습니다:**

```

skwasm   ★ 「작지 않고 실험적」은 낡았습니다 (2026-09-08 에 다시 쟀습니다)
         12.3% 작습니다 · 화면 차이 없습니다 · 교차출처 격리 불필요합니다
         그런데 이득이 1Mbps 에서 1.5초뿐이고(20.44 → 18.90) 폴백을
         실제 기기에서 확인하지 못했습니다. **그래서 안 씁니다** (267번)
         되돌릴 조건 — 폴백을 실제 기기에서 확인했고 그때도 이득이 있으면
```

★ **1Mbps 에서 20.3초**입니다. 데이터가 모자라 속도가 묶인 분이 여기
온다는 것을 잊지 마세요. 기다리는 화면이 그 20초를 말로 채웁니다 —
**그 화면을 없애지 않은 이유가 이 숫자입니다.**

★ **재방문은 못 쟀습니다.** 서버에 ETag 를 붙여 다시 재니 같은 창
새로고침이 32.9초 · 1.63MB 로 줄었는데, 그건 `main.dart.js` 만 캐시를 탄

재방문은 서비스 워커가 답합니다** — 헤드리스로 크롬을 죽였다 켜는 방식으로는
워커가 살아 있는 상태를 못 만듭니다. **못 잰 것을 잰 것으로 적지 않습니다.**

### 분야 아홉 — 첫 화면에 무엇이 펼쳐져 있는가

- [ ] 떼인 돈 · 받을 쪽 → 맨 위가 기한
- [ ] 떼인 돈 · **갚을 쪽** → 압류금지 금액이 맨 위, 겁주는 순서가 아닌가
- [ ] 상속 → 맨 위가 3개월, 통장 경고가 **멈춤 카드**로
- [ ] 임금 → 그만둔 분은 14일, 재직 중이면 매월 지급 조문
- [ ] 보증금 → 「언제부터」 카드에 **D-day 가 안 붙는가**
- [ ] 빚 갚기 → 면책 안 되는 것 다섯이 앞에, 「허가가 원칙」이 「도박」보다 앞
- [ ] 부당해고 → **맨 위가 3개월**, 「부당해고입니다」류가 한 마디도 없는가
- [ ] 속아서 돈을 보냈을 때 → 맨 위가 「어디에 먼저 알리나」, 죄 이야기가 없는가
- [ ] 산 걸 되돌리고 싶을 때 · 인터넷 → 7일, 반품 비용은 **소비자**
- [ ] 산 걸 되돌리고 싶을 때 · **찾아온 판매** → 14일, 반품 비용은 **판매자**. ★ 두 화면을 나란히 놓고 봅니다

## 5. 다음에 할 일 — 순서대로

1. **폰 실기기 확인** — 2026-08-20 아이폰 사파리로 여섯 분야를 봤습니다. 레이아웃·줄바꿈·자판 **문제 없음**. 다만 **글자 크기 축은 실기기로 못 봅니다** — CanvasKit 이 글자를 직접 그려서 시스템 글꼴 크기를 안 따라갑니다. 그 축은 `result_density_test`(세로)와 `result_scale_test`(가로)가 봅니다(DECISIONS 175).
2. **`voice_phishing` (속아서 돈을 보냈을 때)** — 2026-08-20 **열었습니다**(DECISIONS 176·177·178). 전기통신금융사기 특별법의 피해구제 절차이고 역할이 둘입니다(돈을 잃은 쪽 · 계좌가 막힌 쪽). ★ **손해배상 축은 일부러 안 열었습니다** — 원문이 없어서가 아니라 **상대를 특정할 수 없는 분야**라서입니다(DECISIONS 181). 민법 제766조는 **상대를 아는 분야**에서 엽니다 — 중고거래 사기·폭행·교통사고·의료사고. 그때 ①3년(안 날) + ②10년(행위일)에 ③(미성년자 성적 침해)까지 **함께** 넣습니다.
3. **`consumer_withdrawal` (산 걸 되돌리고 싶을 때)** — 2026-08-20 열고 2026-08-21 **방문판매·전화권유 갈래를 붙였습니다**(DECISIONS 186). 한 분야 안에서 법이 둘로 갈립니다 — 인터넷은 전자상거래법(7일·반품비 소비자), 찾아온 판매는 방문판매법(14일·반품비 **판매자**). 매장 갈래는 아직 안 엽니다만 **막다른 골목은 아닙니다** — 길에서 유인돼 매장에서 계약한 경우는 방문판매에 포함된다는 제2조 제1호 괄호를 카드로 폅니다.
4. **`installment_purchase` (할부로 샀거나, 찾아와서 판 것)** — 2026-08-21 열었습니다(DECISIONS 187·188). **손잡이가 둘입니다** — 무르는 것(제8조, 7일)과 아직 안 낸 값의 지급을 거절하는 것(제16조). 둘째에는 **기간이 안 적혀 있어** 7일이 지난 사람에게 남는 유일한 자리이고, 이 분야의 중심입니다. 여섯 호는 원문 그대로 펴고 **우리가 「당신은 4호」라고 붙이지 않습니다.**
5. **`unemployment_benefit` (일이 끊겼을 때)** — 2026-08-21 열었습니다(DECISIONS 189·190·191). **부당해고 바로 다음에 필요한 분야**이고, 12개월이 지나면 남은 날짜가 있어도 사라집니다. ★ **이직 사유를 묻지 않습니다** — 물으면 우리가 제58조 각 호에 대입하는 모양이 됩니다. 제일 급한 빈자리는 **시행규칙 [별표 2] 정당한 이직 사유** 목록입니다.

8. **복지 화면 — 홈의 두 갈래와 법률↔복지 다리까지 만들었습니다** (2026-08-23, DECISIONS 208~212). 아래 「두 번째 문」 절을 보세요. 남은 것 셋입니다 — ① **민간 자료 335건은 미룹니다**(2026-08-24, DECISIONS 236). 「붙이다 만 것」이 아니라 **아직 문이 없습니다** — `loadPrivate()` 를 부르는 화면이 하나도 없습니다. 우리 네 층 어디에도 자리가 없고, 나열하면 우리가 고른 것이 됩니다. 파일은 그대로 둡니다 ② **기존 분야의 막다른 자리**에 이 문을 잇는 것(빚 갚기가 어려울 때 · 일이 끊겼을 때 · 갑자기 나가라고 했을 때). 그때 축은 **이미 있는 질문에서** 끌어옵니다 — 축 때문에 질문을 새로 늘리면 그 순간 복지가 분야가 됩니다 ③ **국민기초생활 보장법 6건** — 다리를 억지로 놓지 말고 **「빚 갚기가 어려울 때」에 그 법을 넣으세요.** 넣는 순간 다리가 따라옵니다. 자리는 제도 셋 옆의 네 번째 갈래가 아니라 「그 전에 — 생계 자체가 안 되면」 한 줄이고, 근거는 제7조(급여의 종류)·제8조(생계급여)입니다. **원문이 없어 이번엔 빈자리로만 적었습니다** (`ct_three_ways.verification.openPart`) ④ **무게 줄이기는 멈췄습니다**(225). 3Mbps 에서 7.1초 · 1Mbps 에서 20.3초입니다. 남은 64%가 CanvasKit 이고 Flutter Web 을 쓰는 한 못 줄입니다.
