# 버바 (beoba)

**법률 문제가 생겼을 때, 오늘 무엇을 해야 하는지와 언제까지인지를 조문 원문과 함께 알려주는 앱**

> 🚧 **개발 중 · 미출시.** 법률 분야 15개 중 일부만 완성되어 있습니다.
> Flutter (Android · Web) · 1인 개발

---

## 무엇을 하고, 무엇을 하지 않나

| 하는 것 | 하지 않는 것 |
|---|---|
| 법에 정해진 **기한**을 오늘 기준으로 계산 | 이길지 질지 **예측** |
| 필요한 **서류와 드는 돈**을 절차별로 계산 | 법률 **상담** · 서류 대필 |
| **조문 원문**을 화면에 그대로 제시 | 특정 변호사 소개 |
| 무료 공적 창구 안내 · 받을 수 있는 복지 연결 | **AI · 외부 추론 엔진** 사용 |

AI를 쓰지 않습니다. 같은 입력에는 언제나 같은 답이 나오고, 사용자는 화면의 조문 원문으로 직접 확인할 수 있습니다.

## 구조 — 계산이 화면을 모른다

```
packages/domain_data/   순수 Dart · Flutter 의존 금지 — 모델 · 로더 · 스키마 검증 · 분야 JSON
packages/engines/       순수 Dart · Flutter 의존 금지 — 기한 · 비용 · 기간 · 관할 계산 엔진
apps/beoba/             Flutter 앱 (화면만)
```

- **분야는 코드가 아니라 데이터**입니다. 법률 분야 하나 = JSON 파일 하나 (`packages/domain_data/assets/domains/`).
- 두 패키지의 pubspec 에 Flutter 가 없어서, 실수로 위젯을 import 하면 컴파일이 실패합니다.

## 빌드가 막는 것 (일부)

| 검사 | 막는 것 |
|---|---|
| 원본 미확보 인용 | 원문을 확보하지 못한 조문 인용 |
| 도달 가능성 | 어떤 답 조합으로도 화면에 안 나오는 항목 |
| 금지 문구 | 「이길 수 있습니다」 같은 승패 예측 · 권유 문구 |
| 개인정보 방침 | 방침의 문장이 코드와 달라지는 것 |
| 정답지(골든셋) | 기한 · 비용 계산 결과의 회귀 |

전체 41가지는 `packages/engines/tool/verify_domains.dart`, 각 결정의 이유는 `DECISIONS.md` 에 있습니다.

## CI

```
정적 분석 (info 도 실패) → 코드 생성 → 테스트 (Dart VM + 위젯 + 경로) → 분야 JSON 전수 검증 → 웹 릴리스 빌드
```

테스트는 Dart VM 에서 돌지만 웹은 정수가 JavaScript 실수(2^53)라 계산이 다르게 깨질 수 있어, 웹 릴리스 빌드를 마지막 단계에 둡니다.

## 실행

```bash
dart pub global activate melos
melos bootstrap
melos run gen        # freezed / json_serializable 코드 생성
melos run verify     # 분석 + 테스트 + 분야 데이터 검증

cd apps/beoba
flutter run -d chrome
```
